Tạo bộ file liên kết

Sinh một lần cả bộ file theo thứ tự gửi: khách hàng → hợp đồng → thông tin gắn với hợp đồng. Mọi custCd, ctrtNo, debtorCustCd, debtorCtrtNo đều khớp nhau. Tải về 1 file zip, mỗi bước một thư mục.

Có mã KH có sẵn thì hợp đồng dùng các mã này thay cho số lượng ở trên và không đăng ký lại KH (LOAN chỉ đăng ký được với KH đã có). Luôn có file INID (có thể chỉ Header/Trailer) cùng đuôi ngày để mở cổng cho các file sau.

Loại cần tạo

Chọn LRPY / DELQ / GUAR / COLL thì tự kèm LOAN, CRPY thì kèm CARD. Seed, vòng đời, Header, đuôi tên file, mã lần chạy và CRLF lấy theo màn hình chính. Bộ file không chèn lỗi.
